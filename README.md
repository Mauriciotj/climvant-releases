# CLIMVANT — Downloads

Aplicativo do **CLIMVANT** (gestão para técnicos de climatização).
Este repositório só guarda os **instaladores das versões** — o código-fonte é
privado.

## Baixar a versão mais recente

Abra a página de **[Releases](../../releases)** e baixe o arquivo do seu
aparelho:

| Arquivo | Plataforma |
| --- | --- |
| `CLIMVANT-Setup-X.Y.Z.exe` | Windows (instalador) |
| `CLIMVANT-X.Y.Z.apk` | Android (instalação manual) |

Sem login, sem conta — o download é livre.

## Como atualizar

- **Android**: baixe o `.apk` da versão nova e instale por cima (se pedir,
  autorize "instalar apps desconhecidos" do navegador usado no download).
- **Windows**: baixe e rode o `CLIMVANT-Setup-X.Y.Z.exe` por cima da instalação
  atual — seus dados permanecem.

Quando o app detecta uma versão nova, ele também mostra o aviso com o link
direto do download.
